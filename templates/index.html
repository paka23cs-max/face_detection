How This Works

What is Face Detection?

Face detection is the process of locating human faces within an image or video frame and marking their position, without identifying who the person is. This project only detects faces — it does not perform face recognition.

What is Eye Detection?

Once a face region is found, a separate classifier searches only inside that region for eyes. Searching inside the face (instead of the whole frame) makes eye detection faster and far less likely to mistake other objects for eyes.

What is Haar Cascade?

A Haar Cascade is a classical, pre-trained machine-learning based object detector. It was trained years ago by OpenCV's developers on thousands of sample face/eye images and is shipped as an XML file. This project uses that pretrained classifier — it does not train a new model.

What is OpenCV?

OpenCV (Open Source Computer Vision Library) is a free, widely-used library of computer vision and image processing functions. It handles webcam access, image conversion, and running the Haar Cascade classifiers used here.

Project Information

This is an academic B.Tech project titled "Real-Time Face and Eye Detection Using Haar Cascade Classifiers and OpenCV." It demonstrates a classical (non deep-learning) computer vision pipeline: webcam capture, grayscale conversion, and detection using OpenCV's pretrained Haar Cascade classifiers, delivered through a Flask web backend and a plain HTML/CSS/JavaScript frontend.
